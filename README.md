# 白夜 · Белые ночи（Ren'Py 版）

陀思妥耶夫斯基《白夜》视觉小说（谷羽译本全文收录），Ren'Py 桌面移植版。

**网页版在线游玩：https://xu2077-q.github.io/white-nights/**

**Windows 版下载：[Releases · v1.0](https://github.com/XU2077-Q/white-nights-renpy/releases/latest)** — 下载 `WhiteNights-1.0-win.zip`，解压后运行 `WhiteNights.exe`。

## 内容

- 谷羽译本《白夜》全文（果麦经典 / 浙江文艺出版社 2020），不删节：六章 655 拍
- 彩色立绘 lit/dim 演出、开场 Ken Burns 序列、结尾全屏 CG、三首公版/CC 授权 BGM
- 章节选择（persistent 解锁）、Ren'Py 自带存档/回想/设置
- 剧本由网页版 `js/script.js` 经生成器全量转写（`game/script.rpy` 头部注释「勿手改」）
